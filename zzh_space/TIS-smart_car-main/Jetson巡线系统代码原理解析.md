### 话题通信关系

| 发布者 | 话题 | 订阅者 | 用途 |
|--------|------|--------|------|
| 相机 | `/camera/color/image_raw` | 巡线节点、YOLO | 只用了彩色图像 |
| 巡线节点 | `/line_follower/centroid` | 转向控制器 | 质心位置(0~1) |
| 巡线节点 | `/cmd_vel_follower` | MUX | 巡线速度(低优先级) |
| 巡线节点 | `/cmd_vel_stop` | MUX | 紧急停车(最高优先级) |
| YOLO | `/hobot_dnn_detection` | 转向控制器 | 检测结果(数字1-8) |
| 转向控制器 | `/cmd_vel_detection` | MUX | 转向速度(中优先级) |
| MUX | `/cmd_vel` | 底盘 | 最终速度命令 |

## 二、巡线主控制器工作流程

```
                    订阅相机图像
                          │
                          ▼
                ┌─────────────────┐
                │  检查启动信号     │ ← 空格键控制
                └────────┬────────┘
                         │ 未启动 → 停车
                         │ 已启动 ▼
                ┌─────────────────┐
                │  图像预处理       │
                │  - 提取ROI区域   │ ← 看线距离(ros(0.3)=看前方30%)
                │  - 高斯模糊      │
                │  - 转HSV/灰度    │
                └────────┬────────┘
                         │
                         ▼
         ┌───────────────────────────────┐
         │     颜色检测（一帧图像顺序执行）   │
         ├───────────────────────────────┤
         │ □ 白色线 → 轮廓 → 质心          │
         │ □ 黄色线 → 计算占比 → 停车       │
         │ □ 红色线 → 判断左右 → 避障       │
         └───────────┬───────────────────┘
                     │
                     ▼
         ┌───────────────────────────────┐
         │       状态判决（优先级）         │
         ├───────────────────────────────┤
         │ ① 黄色永久停止                  │ → /cmd_vel_stop
         │ ② 黄色临时停止(1秒)             │ → /cmd_vel_stop
         │ ③ 红色避障转向(8帧投票)          │ → /cmd_vel_follower
         │ ④ 交叉口探针(固定左转)           │ → /cmd_vel_follower
         │ ⑤ 正常巡线                     │ → /cmd_vel_follower
         │ ⑥ 丢线(0.8秒)                  │ → /cmd_vel_stop
         └───────────┬───────────────────┘
                     │
                     ▼
         ┌───────────────────────────────┐
         │      计算速度和转向             │
         ├───────────────────────────────┤
         │ 误差 error =                   │
         │   (质心x - 图像宽/2) / (宽/2)   │
         │                               │
         │ 转向 yaw = -kp × error         │ ← 左转增强1.15倍
         │                               │
         │ 速度 = target_speed ×          │
         │        (1 - 阻尼×|error|)      │ ← 误差越大越慢
         └───────────┬───────────────────┘
                     │
                     ▼
              发布 /cmd_vel_follower
              发布 /cmd_vel_stop (停车时)
```

### 核心原理

**白线检测**：
1. 二值化：白色区域=255，黑色=0
2. 形态学闭运算：连接断裂的线
3. 找轮廓：选择最大面积轮廓
4. 计算质心：白色区域的几何中心
5. 计算误差：`error = (质心x - 中心x) / (宽/2)`

**控制算法**（比例控制P）：
- 误差为正(线在右) → 需要左转(yaw < 0)
- 误差为负(线在左) → 需要右转(yaw > 0)
- 误差越大 → 转向越快，速度越慢

## 三、YOLO数字识别流程

```
           订阅相机图像
                 │
                 ▼
       ┌─────────────────┐
       │  ROS转OpenCV     │
       │  BGR → RGB      │
       └────────┬────────┘
                │
                ▼
       ┌─────────────────┐
       │   YOLO推理       │
       │   conf=0.15     │ ← 置信度阈值15%
       └────────┬────────┘
                │
                ▼
       ┌─────────────────┐
       │   结果过滤       │
       ├─────────────────┤
       │ 只保留: 1-8      │
       │       D1-D8     │
       └────────┬────────┘
                │
                ▼
       ┌─────────────────┐
       │  构造ROS消息     │
       │ Detection2D     │
       │ - class_id      │
       │ - score         │ （检测框中心点+检测框的宽高）
       │ - center(x,y)   │
       └────────┬────────┘
                │
                ▼
      发布 /hobot_dnn_detection
```

**说明**：
- 检测到数字 → 发布检测结果
- 没检测到 → 发送占位消息(x,y,w,h=99999)
- 每2秒跳过1帧

## 四、转向控制器流程

```
     订阅 /hobot_dnn_detection (YOLO结果)
     订阅 /line_follower/centroid (巡线质心)
                 │
                 ▼
       ┌─────────────────┐
       │ 检查冷却期(2秒)   │
       └────────┬────────┘
                │ 冷却中 → 忽略
                │ 空闲 ▼
       ┌─────────────────┐
       │ 检查质心有效性    │ ← 0.5秒内有效
       └────────┬────────┘
                │ 无效 → 忽略
                │ 有效 ▼
       ┌─────────────────┐
       │ 启动检测窗口      │ ← 累积15帧
       └────────┬────────┘
                │
                ▼
       ┌─────────────────┐
       │ 逐帧检测对齐      │
       ├─────────────────┤
       │ 对每个检测框:     │
       │ - 过滤占位(99999)│
       │ - 计算y方向偏差   │
       │ - 如果|y|≤5cm:   │
       │   数字与线对齐    │
       │   记录x偏差      │
       └────────┬────────┘
                │
                ▼
       ┌─────────────────┐
       │ 窗口满触发转向     │ ← 15帧后
       ├─────────────────┤
       │ yaw = -方向 ×   │
       │       x偏差 ×   │
       │       增益(1.5) │
       │                │
       │ 持续0.8秒       │
       │ 冷却2.0秒      │
       └────────┬────────┘
                │
                ▼
      发布 /cmd_vel_detection
```

**对齐判断**：
- y偏差 ≤ 5% → 数字和线在同一深度，可以转向
- x偏差 > 0 → 数字在线右侧，需左转
- x偏差 < 0 → 数字在线左侧，需右转

**窗口机制**：累积15帧避免误检，选择置信度最高的结果

## 五、MUX多路复用器流程

```
    ┌────────────────────────────────┐
    │   输入话题 (3个)               │
    ├────────────────────────────────┤
    │ 1. /cmd_vel_stop (巡线)        │ ← 最高优先级
    │ 2. /cmd_vel_detection (转向)   │ ← 中优先级(timeout=2s)
    │ 3. /cmd_vel_follower (巡线)    │ ← 低优先级
    └────────────┬───────────────────┘
                 │
                 ▼
    ┌────────────────────────────────┐
    │      优先级判决逻辑             │
    ├────────────────────────────────┤
    │ if (stop信号未超时0.5s)       │
    │     → 输出stop                 │
    │ else if (detection未超时2s)    │
    │     → 输出detection            │
    │ else                           │
    │     → 输出follower             │
    └────────────┬───────────────────┘
                 │
                 ▼
           /cmd_vel (输出)
                 │
                 ▼
          [底盘驱动]
```

**超时机制**：
- stop超时0.5秒后失效
- detection超时2秒后失效，自动切回follower
- follower无超时，一直有效

## 六、完整运行示例

### ：正常巡线
```
1. 巡线节点检测白线，质心x=320(中心)
2. error = 0, yaw = 0, speed = 0.35
3. 发布 /cmd_vel_follower: {linear: 0.35, angular: 0}
4. MUX无stop/detection → 输出follower
5. 底盘前进
```

### 数字识别转向
```
1. YOLO检测到数字"3"在右侧
2. 转向控制器累积15帧
3. x偏差=0.125 → yaw=-0.1875(左转)
4. 发布 /cmd_vel_detection: {linear: 0.2, angular: -0.1875}
5. MUX有detection → 输出detection(高优先级)
6. 底盘左转0.8秒
7. 2秒后detection超时，自动切回巡线
```

### 黄线停车
```
1. 巡线节点检测黄线占比12%
2. 发布 /cmd_vel_stop: {linear: 0, angular: 0}
3. MUX有stop → 输出stop(最高优先级)
4. 底盘立即停车
5. 0.5秒后stop超时，恢复巡线
```

### 红色避障
```
1. 巡线节点检测红色在分界线左侧
2. 连续8帧投票确认
3. 发布 /cmd_vel_follower: {linear: 0, angular: -0.6}(右转)
4. MUX无stop/detection → 输出follower
5. 底盘右转1秒
```
